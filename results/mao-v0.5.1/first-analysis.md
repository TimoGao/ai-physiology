# MAO v0.5.1 — Longitudinal Health Benchmark（纵向健康基准）首轮结果

## 实验规模
- 200个随机种子
- 每个seed同时生成1条缓慢退化轨迹 + 1条健康对照轨迹
- 共400条纵向轨迹
- 两类监测器分别评估，共800次监测评估
- 每条轨迹240个时间步

## 两个比较对象
1. Adaptive Monitoring Baseline（自适应监控基线）
   - moving average（移动平均）
   - trend/slope（趋势/斜率）
   - rolling error（滚动错误）
2. Physiology Monitor（生理监测器）
   - Homeostatic Debt（稳态债务）
   - Recovery Reserve（恢复储备）
   - 债务趋势 + 储备下降趋势

## 核心结果

| 指标 | 自适应监控 | 生理监测 |
|---|---:|---:|
| 未来故障预测AUC | 0.765 | 0.781 |
| 提前预警召回率 | 100.0% | 92.5% |
| 假提前预警率 | 95.8% | 37.1% |
| 真阳性平均提前量 | 162.8 | 103.5 |

## 当前判断

这是第一次出现一个比较像样的“增量信号”。

Physiology Monitor 的 AUC 从 0.765 提高到 0.781，提升不算大；但它把假提前预警率从 95.8% 大幅降低到 37.1%。

代价是：
- 提前预警召回率从 100.0% 降到 92.5%
- 真阳性平均提前量从 162.8 个时间步降到 103.5

也就是说，生理监测器目前表现得更“克制”：
- 少报很多假警报
- 预测排序能力略强
- 但会漏掉一部分故障，而且报警更晚

这比前面“两个系统结果完全一样”更有研究价值，因为 Debt / Reserve 开始显示出与普通趋势监控不同的行为特征。

## 现在仍然不能下的结论
不能说：
- Homeostatic Debt 已经被证明有效
- Recovery Reserve 已经被证明能预测真实AI故障
- AI慢性病已经被证明存在

因为当前仍是 synthetic benchmark（合成基准），而且故障标签本身由我们设计的生成机制产生。

## 下一步应该做什么
下一步不是马上接真实LLM，而是先做 v0.5.2：
1. threshold calibration（阈值校准）
2. ROC / Precision-Recall 比较
3. 让两种监测器在相同 false-positive budget（误报预算）下比较
4. 加入更多退化形态，而不是只有一种缓慢线性漂移
5. 做 Debt / Reserve 消融，验证到底是Debt还是Reserve在提供预测信号

只有v0.5.2仍保留增量信号，再进入真实LLM。
