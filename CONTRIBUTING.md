# Contributing

AI Physiology is an early research framework.

Contributions are especially welcome in:
- biological accuracy
- distributed systems architecture
- agent runtime design
- cybernetics and control
- artificial life
- security and immune analogues
- experimental design
- terminology and falsification

## Proposal process

Major conceptual changes should be submitted as an **AIP (AI Physiology Proposal)**.

Suggested structure:
1. Problem
2. Biological reference
3. AI definition
4. Inputs/outputs
5. Failure modes
6. Interface
7. Testable predictions
8. Alternatives / falsification
