# Biological Reference Model

AI Physiology uses the human body as a reference model because it is a well-characterized open complex system that maintains long-term organization under changing environmental conditions.

The framework does **not** assume one-to-one biological equivalence. Biological organs are used to identify indispensable classes of system function.

| Human structure | Biological role | AI physiology question |
|---|---|---|
| Cerebrum | high-level cognition | where are reasoning, planning, abstraction located? |
| Cerebellum | prediction, motor learning, rapid error correction | what handles low-latency correction and skill consolidation? |
| Brainstem | basic life control | what keeps the AI minimally alive when higher cognition fails? |
| Spinal cord | signal relay and reflex | what should execute without consulting the central model? |
| Heart | circulation pump | what continuously drives internal task/resource/state circulation? |
| Blood | shared transport medium | what common internal medium carries heterogeneous payloads? |
| Liver | transformation, synthesis, detoxification, storage | what converts external material into safe internal resources? |
| Kidney | filtration and internal balance | what continuously regulates internal data/state quality? |
| Endocrine system | slow global regulation | what broadcasts organism-wide modes and priorities? |
| Immune system | anomaly recognition and defense | what identifies self/non-self, corruption, infection, attack? |
| Skin | boundary and sensing | where does organism identity end and the environment begin? |
| Musculoskeletal system | action | how does the organism change digital or physical environments? |

## Key lesson

The body is not a CPU with peripherals. It is a collection of semi-autonomous organs coupled through multiple whole-body networks and stabilized through feedback.
