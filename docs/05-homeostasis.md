# Homeostasis and AI Vital Signs

## Homeostasis

AI homeostasis is the continuous regulation of internal variables within viable operating ranges.

It is an organism-level outcome, not a single organ.

## Candidate AI Vital Signs

- compute availability
- energy consumption
- resource pressure
- context saturation
- memory integrity
- stale-memory ratio
- error accumulation
- task backlog
- latency
- tool failure rate
- security alert level
- identity consistency
- recovery capacity
- external dependency ratio

## Control loop

1. sense internal variable
2. detect deviation
3. select control response
4. signal relevant organ(s)
5. execute correction
6. observe response
7. restore or redefine target range

## Research problem

A key open question is which variables are truly organism-level vital signs versus implementation-specific telemetry.
