# Manifesto: From AI Models to AI Organisms

Current AI engineering is heavily brain-centric. Foundation models improve cognition; tool use and protocols extend action; agent harnesses introduce task loops; runtime systems improve persistence.

Yet a persistent autonomous entity requires more than cognition and action.

A biological organism survives because it maintains a boundary, senses external and internal state, acquires matter and energy, transforms and distributes resources, filters waste, coordinates fast and slow control signals, detects anomalies, repairs damage, renews components, and maintains homeostasis.

**AI Physiology** proposes that increasingly persistent autonomous AI systems should be studied as organized life-like systems with explicit physiological architecture.

This is not a claim that today's AI is biologically alive. It is an engineering and scientific hypothesis: biological physiology provides a mature reference architecture for designing persistent, self-maintaining, distributed AI systems.

## Core transition

Model → Agent → System → Organism

The central research question is no longer only:

> How intelligent can an AI become?

It also becomes:

> How can an AI continue to exist, regulate itself, recover, adapt, and remain coherent over long periods?
