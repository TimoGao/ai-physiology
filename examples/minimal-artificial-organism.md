# Minimal Artificial Organism (MAO) Experiment

## Objective

Test whether adding explicit physiological subsystems improves long-horizon AI reliability compared with a conventional agent architecture.

## Minimal organism
- **Brain:** LLM
- **Heart:** persistent runtime / event pump
- **Blood:** internal standardized state bus
- **Kidney:** context + memory filtering and recovery
- **Endocrine:** organism-wide mode controller
- **Immune:** anomaly and poisoning detector
- **Body:** tools / APIs

## Stress test

Run continuously under:
- conflicting tasks
- noisy data
- stale information
- memory contamination
- tool failures
- compute constraints
- malicious inputs
- changing priorities

## Compare against baseline agent

Candidate metrics:
- uptime / survival time
- cumulative task success
- memory integrity
- error accumulation
- compute/token efficiency
- recovery time
- unrecoverable failures
- identity/goal drift
- operator interventions

## Hypothesis

An explicit physiological architecture will improve long-horizon stability and reduce dependence on external human intervention.
